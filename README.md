# 欧式期权定价模型：Black-Scholes 解析解 + 蒙特卡洛模拟实现

本项目为《随机过程》与《随机分析》课程的延伸实践，基于Python实现欧式期权的两种经典定价方法：Black-Scholes 解析解与蒙特卡洛数值模拟，并对两者结果进行对比分析。

作为金融工程/量化金融方向的标准入门项目，本项目完整展示了金融数学建模、数值计算与风险分析能力。

## 项目背景
期权定价是金融工程领域的核心问题之一。Black-Scholes模型提供了欧式期权定价的解析解，而蒙特卡洛模拟则是一种通用、灵活的数值方法，通过模拟标的资产价格路径来估计期权价值。

本项目结合两种方法，不仅加深对金融数学理论的理解，更通过对比分析，展示了解析方法与数值方法的适用场景与误差边界。

## 技术栈
- Python 3.11：主开发语言，实现模块化定价逻辑
- NumPy：数值计算与几何布朗运动随机过程模拟
- SciPy：统计函数与 Black-Scholes 解析解计算
- Matplotlib：标的资产价格路径可视化与结果分析

## 核心功能
1. **Black-Scholes 解析解定价**：实现欧式看涨/看跌期权定价，并计算核心希腊字母（Delta、Gamma、Vega）。
2. **蒙特卡洛模拟定价**：基于几何布朗运动模拟标的资产价格路径，估计期权价值。
3. **方法对比与误差分析**：对解析解与数值解的定价结果进行误差对比，分析方法差异。
4. **波动率敏感性分析**：分析期权价格对标的波动率（σ）的敏感度，验证定价模型的合理性。

## 运行结果
在参数设置 `S=100, K=100, T=1, r=0.05, σ=0.2` 下：
- Black-Scholes 理论价格：10.4506
- 蒙特卡洛模拟价格：10.3991
- 两者定价误差：0.0515

## 项目亮点
- 理论落地：将《随机过程》课程中的布朗运动、伊藤引理等理论，直接应用于真实的衍生品定价场景
- 对比验证：同时实现解析解与数值解，通过误差分析理解不同定价方法的适用场景
- 工程规范：模块化代码设计，参数清晰可调，便于扩展与复现，符合量化项目的开发规范

## 优化方向
1.  **模型扩展**：当前实现针对欧式期权定价，后续可扩展支持美式期权、亚式期权等路径依赖型期权，提升模型通用性。
2.  **参数校准**：引入市场真实波动率曲面数据，对模型参数进行校准，提高定价结果的市场贴合度。
3.  **性能优化**：对蒙特卡洛模拟部分进行向量化与并行计算优化，或采用低差异序列（Sobol序列）提升计算效率与收敛速度。
4.  **风险分析深化**：补充希腊字母（Delta、Gamma、Vega）的动态对冲分析，构建完整的期权风险管理框架。
5.  **可视化增强**：增加定价曲面、波动率微笑等交互图表，提升结果的直观性与分析能力。
